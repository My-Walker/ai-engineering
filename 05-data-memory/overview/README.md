# L5 数据与记忆层 · 总纲

## 定位

为 Agent 提供任务依据：代码与文档检索、RAG、会话记忆、过程工件等；关注召回质量、隐私、新鲜度与权限。

## 职责

- 上下文来源的组织与检索策略  
- 记忆写入/失效/隔离（租户、仓库、会话）  
- 与敏感信息相关的进入模型前处理（脱敏等）

## 非职责

- 不替代规范门禁与 SOP（→ L3）  
- 不替代模型本身（→ L1）  
- 存储适配器若通过 MCP/API 暴露，实现可与 L4 协作，但「记忆策略」归属本层

## 现状

规划阶段。现阶段多借用 IDE / 宿主自带的代码索引与会话能力；自建记忆服务有明确需求再开产品。
