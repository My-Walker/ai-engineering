# L1 模型层 · 总纲

## 定位

提供推理与生成能力：基座/微调/多模型路由、解码策略、对齐基线、上下文窗口与成本延迟。

## 职责

- 模型选型与切换策略  
- 质量 / 成本 / 延迟等模型侧指标  
- 模型级安全对齐基线（与应用鉴权、规范门禁互补）

## 非职责

- 不写团队 SOP / skills / rules（→ L3）  
- 不实现 MCP 或业务 API 适配（→ L4）  
- 不做产品 UX 与会话产品（→ L2）  
- 不拥有业务知识库本体（→ L5；模型只消费上下文）

## 现状

规划阶段。推理能力暂由 Cursor / 厂商模型提供，本层以文档演进为主。
