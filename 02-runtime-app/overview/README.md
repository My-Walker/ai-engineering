# L2 能力与应用层 · 总纲

## 定位

人与系统使用 AI 的运行时与产品面：Agent 宿主、会话、权限、交互模式、人机分工。

## 职责

- 加载并执行 L3 规范（锚点、会话内路由）  
- 调用 L1 模型、L4 工具，读写 L5 记忆/上下文  
- 产品能力：Ask/Agent/Plan 等模式、权限与租户（若有）

## 非职责

- 不承载可版本化分发的团队 SOP 正文（→ L3 规范包）  
- 不实现具体 MCP Server（→ L4）  
- 不替代模型权重与训练（→ L1）

## 现状

**先借用现成宿主（如 Cursor）**，不自建应用仓。  
本层文档记录借用策略、与 L3 的加载关系、以及将来自建应用的触发条件。

## 与规范层的关系

应用负责「真的加载规范」；规范负责「Agent 被允许怎么做」。  
当前规范包通过安装锚点挂到宿主项目根，由 Cursor 等加载。
