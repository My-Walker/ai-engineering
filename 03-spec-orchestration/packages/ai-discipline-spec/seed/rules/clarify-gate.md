# 澄清门

## 结束判定

会影响行为或验收的项（含测试缝），只有两种关法：

1. 用户确认该选项。
2. 用户书面将该项标为范围外，且不影响本切片验收。

推荐、模型自选、「你看着办」、进入下一步、用户暂停澄清，都不算结束。

## 未结束

只可继续澄清：给出选项，并标明推荐。不得把未决写成已定，也不得执行。不按后续产物或流程逐个放行。

即使用户要求「直接实现」或「先出 Plan」，也不得结束，不得提供「跳过未决」类选项。
