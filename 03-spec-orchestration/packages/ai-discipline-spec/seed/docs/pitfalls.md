# 项目坑册（入口）

给 Agent 的**薄入口**：全局高频坑 +（可选）分册索引。  
条目宜具体：症状 → 错误做法 → 正确做法 → 相关路径。  
反复踩且能收成一句硬禁令的 → 晋升为 `role: gate`（必要时 always），本处可留链接。

## 全局坑

### 设计讨论被收成「最小改动」

- **症状**：问「怎么设计 / 你会怎么做 / 一次做好」时，先只给两文件、缩 scope、顺着用户已有倾向；被追问后才改口出完整契约。
- **错误做法**：把实现态的「最小改动」当成设计态的最优方案；用分期切片替代终态协议。
- **正确做法**：先完整正确方案（契约与终态），再单列可选分期；推荐可与用户倾向不同但须写明理由。服从 `rule:design-depth-gate`。
- **相关路径**：`.ai-discipline/rules/design-depth-gate.md`

（业务仓可在下方继续追加本项目坑。案例多了拆到 `pitfalls/`。）
