# 分析定范围

`sop:explore-review` 第一步。只定范围，不开始改码。

## 进入条件

- 当前任务是只读分析 / 评审 / 答疑，或路由选定 `sop:explore-review`。

## 核心规则

1. 先复述对象与目标，再收窄范围。
2. 范围会影响结论且不明时：列选项+推荐，等人确认（或确认可跳过追问）。
3. 默认输出形态：「总判 + 按严重度的发现与改进顺序」；用户只要答疑则改为「直接答问题」。
4. 服从后续 `rule:explore-readonly`：本 SOP 内默认不改业务代码。

## 做法

1. 一句话复述分析对象、目标、非目标（不做的事）。
2. 范围模糊时提问（模块边界、深度、是否含性能/安全等）。
3. 确认输出形态与是否允许提出「后续可落地」建议（仍不在本 SOP 内直接改码）。

## 完成标准

- 对象、目标、输出形态已确认（或用户明确跳过并默认形态适用）。
- 未开始业务代码修改。
