# L4 工具与集成层 · 总纲

## 定位

扩展 Agent 可调用的外部能力：MCP、CLI、HTTP API、浏览器等；负责协议、鉴权、超时重试与副作用边界。

## 职责

- 工具接入与生命周期  
- 最小权限与凭证管理  
- 调用可靠性（错误、重试、幂等等，按需）

## 非职责

- 不编写团队 SOP 主路径（→ L3）  
- 工具进程不解释 rules/skills 文件；由 L2 Agent 在 L3 约束下决定是否/如何调用  
- 「某工具怎么用」的短约定可沉淀为 L3 skills，实现仍在本层

## 与 MCP

MCP 是本层的一种标准插槽，**不是**工具层的全部。

## 现状

- 可入库工具包按需放在 `packages/`。
- 含业务加解密 / 表结构的本地运维 MCP **不入库**（见仓库根 `.gitignore`），仅本机使用；密钥与导出目录在用户机 `SCS_LOCAL_DB_HOME`。
